# UX‑принципы и панель команд TimeWise Bot

Документ фиксирует правила дружественного интерфейса Telegram‑ботов и описывает панели задач для ролей Admin и User в соответствии с ТЗ «TimeWise».

## 1. Базовые принципы удобного бота

1. **Прозрачный старт** — команда `/start` сообщает, что умеет бот, и сразу показывает доступные действия (инлайн‑панель).  
2. **Постоянная подсказка** — `/help` и `/menu` доступны в любом состоянии и возвращают пользователя к панели.  
3. **Минимум текста, максимум действий** — ключевые сценарии запускаются кнопками; длинные описания вынесены в отдельные сообщения.  
4. **Ролевая персонализация** — пользователи видят только релевантные кнопки, чтобы избежать «шумных» меню.  
5. **Подтверждения и обратная связь** — по каждому нажатию бот отвечает `callback.answer()` и отправляет сообщение со статусом (даже если функция ещё «в разработке»).  
6. **Логирование действий** — каждое взаимодействие будет в будущем попадать в AuditLog (учитывается в архитектуре).  
7. **Fail-safe** — при недоступности функции бот показывает заглушку с планами, а не молчит.

## 2. Панели задач

### 2.1. Администратор (Admin)

| Кнопка | Назначение | Будущий функционал (ссылка на ТЗ) |
|--------|------------|-----------------------------------|
| 📇 Контакты | Работа с `Contacts`, импорт CSV, мягкое удаление | ТЗ п. 3.1.1 |
| 🗓 Рассылки | Просмотр `JobQueue`, статусы pending/sent/failed | ТЗ п. 3.1.2 |
| 📝 Шаблоны | Версионирование `Templates`, стили и blacklist | ТЗ п. 3.1.3 |
| 📊 Мониторинг | Метрики Prometheus/Grafana, отчёты `/stats` | ТЗ п. 6 |
| ⚙️ Настройки | APScheduler, retries, роли, интеграции | ТЗ п. 3.2/3.4 |
| ✅ Approval | Панель согласований `ApprovalQueue` | ТЗ п. 4.6 |

Каждая кнопка сейчас выводит текстовую заглушку с описанием будущего действия.

### 2.2. Пользователь (User / Viewer)

| Кнопка | Назначение |
|--------|------------|
| 🎉 Мои поздравления | Предпросмотр текстов, где пользователь ответственен |
| 🕒 Напоминания | Ближайшие события и подтверждение получения |
| 📤 Отправить отзыв | Канал связи с редакторами шаблонов |
| ℹ️ Помощь | Инструкции и контакты администраторов |

### 2.3. Расширения

- Добавление ролей `Editor` (работа с шаблонами) и `Viewer` (отчёты) через отдельные панели.  
- Встроенные формы (Aiogram `FSM`) для пошагового добавления контактов и согласования поздравлений.  
- Поддержка «быстрых ответов» (ReplyKeyboard) в сценариях, где подтверждение важно.
